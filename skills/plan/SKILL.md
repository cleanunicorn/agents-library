# plan

Read the Define output.

- Slice work vertically: each task is one complete, verifiable path.
- Task = scope + acceptance criteria + verification steps.
- Order tasks by dependency.
- Add the task list to the issue, opening with a `## Progress` checkbox list. No code here.
