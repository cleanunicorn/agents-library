# build

Per task:

1. Read its acceptance criteria and the code it touches.
2. Write a failing test for the behavior. Red.
3. Write the minimum code to pass. Green.
4. Run targeted tests per cycle, full suite per task.
5. One conventional commit per task.

If blocked or AC is wrong, stop and update the plan — don't widen scope.
